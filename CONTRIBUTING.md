# Contributing

1. Find an issue labelled `good first issue`
2. Fork, branch, and commit with `Closes #N` in the message
3. Open a pull request — a maintainer will review it within the SLA

## Keyboard-only workflow

1. Open the repository Issues page and use the Tab key to move through issue links.
2. Open a `good first issue`, then follow its acceptance criteria.
3. Press `.` on the repository page to open the web editor, or edit the JSON file locally.
4. Validate the JSON before committing.
5. Open a pull request with a descriptive title and include `Closes #9` in its description.
